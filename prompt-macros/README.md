# Prompt Macros

This folder holds a small starter macro set.

These are not platform-native commands. They are reusable reasoning cues: short names that trigger a specific way of structuring a response or a working session.

They are most useful in chat-first LLM workflows, where you want portable reasoning shortcuts without native skill support. In agentic environments like Claude Code or Codex, many of the same patterns are better encoded as skills or repo instructions.

Included here:

- `optimize.md`
- `steps.md`
- `variants.md`
- `pushback.md`
- `snapshot.md`

Use them because they keep recurring, not because a bigger library looks more impressive.
