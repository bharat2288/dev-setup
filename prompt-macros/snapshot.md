# SNAPSHOT

## Purpose

Capture enough context to resume cleanly later.

## Trigger

- `SNAPSHOT`
- `SNAPSHOT[migrate]`
- `SNAPSHOT[document]`

## Modes

### migrate

Use when you need a compact resume prompt:

```text
Continuing work on [topic].
- Goal: [one line]
- Current state: [2-3 bullets]
- Active task: [current step]
Continue with: [next move]
```

### document

Use when you want a fuller session record:

- what was done
- what was created
- key decisions
- open questions
- next steps

## Good for

- context compaction
- handoffs
- session closeout

## Pairs well with

- `STEPS`
- `PUSHBACK`
